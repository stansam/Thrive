# Architecture Map

This document maps the codebase structure, identifying Server vs. Client boundaries and routing logic.
Generated by Agent.

## Legend

- `[Client]`: Contains "use client" directive or is a Client Component.
- `[Server]`: Default Next.js Server Component.
- `[Layout]`: Layout component wrapping a route segment.
- `[Page]`: Page component defining a route.
